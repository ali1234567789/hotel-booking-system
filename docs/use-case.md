Use Case

Актерлер
Қонақ
Әкімші

Қонақтың әрекеттері
1. Бөлмелер тізімін қарау.
2. Бос бөлмені таңдау.
3. Бөлмені брондау.

Әкімшінің әрекеттері
1. Брондаулар тізімін қарау.
2. Брондау ақпаратын тексеру.
3. Брондауды басқару.

Негізгі сценарий
Қонақ жүйеге кіріп, бос бөлмені таңдайды және брондау ақпаратын енгізеді. Жүйе брондау туралы ақпаратты сақтайды.
