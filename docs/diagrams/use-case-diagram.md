# Use Case диаграммасы

Hotel Booking System жүйесінің қолдану сценарийлері.

```mermaid
flowchart LR
    Guest(["👤 Қонақ"])
    Admin(["👤 Әкімші"])

    subgraph System["Hotel Booking System"]
        UC1("Бөлмелер тізімін қарау")
        UC2("Бос бөлмелерді іздеу")
        UC3("Бөлмені брондау")
        UC4("Брондауды өзгерту")
        UC5("Брондауды болдырмау")
        UC6("Бөлмелерді басқару")
        UC7("Брондауларды қарау")
    end

    Guest --> UC1
    Guest --> UC2
    Guest --> UC3
    Guest --> UC4
    Guest --> UC5

    Admin --> UC6
    Admin --> UC7

    UC3 -. include .-> UC2
```

## Актор сипаттамасы

| Актор | Рөлі |
|---|---|
| Қонақ | Бөлмелерді қарайды, іздейді, брондайды, брондауды өзгертеді немесе болдырмайды |
| Әкімші | Бөлмелерді қосады, өңдейді, жояды және барлық брондауларды қарайды |
