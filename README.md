Жоба туралы:
Бұл жоба қонақүй бөлмелерін брондауға арналған ақпараттық жүйе болып табылады. Жүйе қонақтарға бөлмелерді онлайн қарап, таңдап, брондауға мүмкіндік береді, ал әкімшіге брондаулар мен бөлмелерді басқаруға көмектеседі.

Жобаның мақсаты
Қонақтарға бөлмелерді таңдауға және брондауға мүмкіндік беру, сонымен қатар қонақүй әкімшілігінің брондауларды есепке алу және басқару жұмысын жеңілдету.

Негізгі мүмкіндіктері
- Қонақүй бөлмелері туралы ақпаратты қарау
- Бос бөлмелерді таңдау
- Бөлмені брондау
- Брондау ақпаратын сақтау
- Төлем ақпаратын сақтау және статусын тексеру
- Әкімшінің брондауларды басқаруы

Қолданушылар (актерлер)
- **Қонақ**: бөлмелерді қарайды, таңдайды және брондайды
- **Әкімші**: бөлмелер мен брондауларды басқарады
